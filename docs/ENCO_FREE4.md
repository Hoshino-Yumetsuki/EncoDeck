# OPPO Enco Free4 适配核对

2026-10-25 依据本机欢律 17.6.5 的型号配置及协议调用路径核对。以下是互操作事实；测试使用模拟设备，尚未完成 Free4 真机验证。未复制应用源码或分发 APK、完整配置、资源及密钥。

| 项目 | Free4 的配置及处理 |
| --- | --- |
| 型号识别 | 标准版 `068C10`；丹拿版 `06C010`，分别按蓝牙名称识别，再以设备上报的产品 ID 确认 |
| 控制服务 | 优先 `0000079A-D102-11E1-9B23-00025B00A5A5` |
| 降噪 | 父索引 1；深度 4、中度 5、轻度 6、智能 7；自适应为独立索引 11，无自适应偏好档位 |
| 关闭 / 通透 | 写入 0 / 2；分别兼容设备上报 3 / 8 |
| 长按循环 | 双耳共用，读写类型 1；可选索引依次为 1、11、2、0，至少选择一种模式 |
| 预设 EQ | 基础索引 0、1、2；索引 7 从固件 118 起提供；丹拿版另有索引 3，以及从固件 136 起提供的索引 8 |
| 自定义 EQ | 62、250、1000、4000、8000、16000 Hz，增益 −6～+6，最多 3 组 |
| 空间音频 | 关闭 / 固定，无头部跟踪；设备未声明 V2 命令时使用功能 27；开启空间音频先关闭 Hi-Res |
| 游戏模式 | 默认使用功能 6；设备声明游戏音效命令后按运行时能力切换到功能 40 |
| 智能音量调节 | 配置 `controlAutoVolumeSupport=1`；状态 ID 28，写入 `0x0403 [1C 00/01]`，随后 `0x010D [01 1C]` 回读确认 |

智能音量调节此前只有启动查询，没有状态映射或界面入口。现已接入“更多设置”，提供中文和英文文案；在耳机尚未返回该状态时禁止写入。该逻辑也适用于同样声明此功能的目录型号。

核对位置：欢律 `ControlAutoVolumeActivity` 的开关调用（功能 28）、`PollCommandManager` 的状态 ID 构造和共享降噪循环查询路径，以及型号白名单中的上述两个产品 ID。功能支持列表与命令能力位图是不同概念，不将功能 ID 28 当作命令位图的第 28 位。

专项测试见 `OppoFree4Tests`：覆盖两个版本的功能边界、EQ 固件门槛、降噪模式往返、共享长按循环的两字节掩码、V1 空间音频、单开关游戏模式，以及智能音量读写与无状态拒绝写入。

真机后续需核对：连接初始化、实际能力位图、固件版本、全部降噪档位、智能音量调节、手势、自定义 EQ 和双设备连接。当前模拟器能力位图仅用于测试，不作为 Free4 实机抓包证据。

## 设备管理操作修复

设备双连开关（功能 17）、读取设备列表（命令能力位 29）和远程管理（命令能力位 59）是独立能力。此前界面仅根据双连配置展示连接、断开、移除及优先设备设置，导致仅支持列表的固件也出现无法使用的按钮。

现按握手返回的 `0x0429` 能力适配界面；不支持时保留双连开关和设备列表，提示在对应设备的蓝牙设置中操作。支持时，连接、断开、移除必须回读设备列表并确认目标设备状态，不能仅凭 ACK 或任意列表通知判定成功。等待确认期间禁用重复操作；显式查询返回空列表时清除旧记录。此修复不会使固件未提供的命令变得可用，反馈设备的实际能力仍须以其诊断报告为准。
