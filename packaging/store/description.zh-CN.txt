在 Windows 上轻松管理你的蓝牙耳机，不用为了切个降噪再拿起手机。

EncoDeck 把手机耳机 App 里常用的设置搬到了电脑上：查看电量、切换降噪、调整音效、管理触控手势。平时只留一个托盘图标，需要时点一下就能操作。

以 OPPO / 一加耳机为主要适配对象，同时支持多个主流品牌的部分耳机。不同型号可用的功能不同，EncoDeck 会按耳机的实际能力显示对应设置。

【电量与状态】
• 显示左耳、右耳和充电盒电量，头戴式耳机显示单组电量
• 充电、佩戴状态与固件版本（视型号而定）
• 电量过低提醒；充电盒的旧读数会标明“上次读取”

【降噪控制】
• 降噪 / 通透 / 关闭 / 自适应，以及降噪强度
• 用耳机手势或手机切换后，界面同步更新
• 全局快捷键：一键切换降噪模式，全屏游戏中也能用

【音效】
• 耳机内置 EQ 预设，部分型号支持自定义 EQ
• 空间音频与头部跟踪、动态低音、游戏低延迟模式

【耳机设置】
• 触控手势、佩戴检测、提示音量
• 查找耳机、贴合度检测
• 双设备连接管理

【Windows 体验】
• 托盘快捷面板，支持浅色 / 深色主题
• Windows 11 中按 Win + A 打开快速设置时，耳机面板贴在上方
• 耳机连接时弹出设备卡片和连接动画，全屏时不打扰
• 首页按型号显示设备图片或可旋转的 3D 模型
• 后台运行、开机启动，通过 Microsoft Store 自动更新

使用前请先在 Windows 蓝牙设置中配对并连接耳机。部分型号的设备图片和动画需要首次联网获取。

EncoDeck 是开源的非官方工具，与各耳机品牌没有关联。除 OPPO Enco X4 外，多数型号尚未经过真机测试，欢迎在 GitHub 反馈测试结果：https://github.com/TIANLI0/EncoDeck
